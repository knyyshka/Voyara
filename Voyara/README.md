# Voyara

### 🌍 Voyara – AI-Powered Travel Recommendation System

Voyara is an intelligent travel recommendation system that combines the K-Nearest Neighbors (KNN) algorithm with AI-powered reasoning using the Groq API to suggest personalized travel destinations along with realistic budget estimates.

## 🚀 Features

- User authentication (LocalStorage-based)
- KNN-based travel recommendation engine
- AI-powered travel insights using Groq (LLaMA 3.1 8B Instant)
- Real-world trip budget estimation (INR)
- Personalized destination ranking
- Destination image gallery
- Dark mode support
- User search history tracking
- Smart prefetching for faster recommendations

---

## 🏗️ Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**AI**
- Groq API (LLaMA 3.1 8B Instant)

**Machine Learning**
- K-Nearest Neighbors (K = 5)
- Euclidean Distance

**Storage**
- Browser LocalStorage

---

## 🧠 How It Works

1. The user enters travel preferences such as budget, weather, and trip duration.
2. The KNN algorithm compares the user's preferences with the destination dataset.
3. The top matching destinations are selected.
4. The AI engine:
   - Calculates realistic travel costs
   - Generates personalized travel insights
   - Explains why each destination is recommended
5. The final recommendations are displayed with similarity scores, estimated budgets, and AI-generated explanations.

## 📋 Prerequisites

Create a `.env` file in the project root and add your Groq API key:

```env
GROQ_API_KEY=your_api_key_here
```
